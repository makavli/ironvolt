# Credits

IRONVOLT's art, sound effects, font and code are original and made for this game: the pictures are drawn in
code at start-up and the sound effects are synthesized at start-up.

Music (`ironvolt/songs/`): made for IRONVOLT with [ACE-Step 1.5](https://huggingface.co/ACE-Step/Ace-Step1.5) XL
(MIT licence), a music model run on our own PC, from a written description of each mission's band; each song is then
cut into a seamless loop.

Built with:
- [pygame-ce](https://github.com/pygame-community/pygame-ce), LGPL-2.1
- [SDL 2](https://www.libsdl.org/), zlib licence (bundled with pygame-ce)
